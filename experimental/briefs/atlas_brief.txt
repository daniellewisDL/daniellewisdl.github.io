FORMAT NOTE FOR THE READING LLM: sections are delimited by "## " headings. Items are "KEY: value" or "- bullet". Anything in
[square brackets] is a parameter. Anything marked MUST is a hard requirement; SHOULD is a strong preference. Numbers quoted here
are the values the original build used; the authoritative dataset is the ATLAS_DATA object (see §3), which the builder must be given.

## 1. PURPOSE
A single-page, offline-capable (except CDN libs/fonts), editorial-light data story built from the "Term Sheet Guide 2026 Vol.1"
(HSBC Innovation Banking / UKBAA; UK venture capital term sheets; 711 sheets, 2025 deals) with the 2025 and 2024 editions folded in
for multi-year history. Goal: extract all quantitative data, recast it into novel views, and attach ACTIONABLE conclusions for two
audiences (founders raising, investors deploying). Every insight is labelled founder / investor / both. There is NO audience toggle.

## 2. DELIVERABLE / STACK
- ONE self-contained file: index.html with inline <style> and inline <script> (data embedded). Vanilla JS, no framework, no bundler.
- Libraries (script tags, cdnjs): d3 7.9.0 (cdnjs.cloudflare.com/ajax/libs/d3/7.9.0/d3.min.js), d3-sankey 0.12.3
  (…/d3-sankey/0.12.3/d3-sankey.min.js), three.js r128 (…/three.js/r128/three.min.js). DO NOT rely on three's OrbitControls (not on
  cdnjs for r128): orbit/zoom is hand-written with pointer events.
- Fonts (Google Fonts link, with system fallbacks): Inter (UI), Source Serif 4 (headings/numbers). Mono not required.
- Data: a global `const D = ATLAS_DATA;` supplied by the data file (§3). All charts read from D; no numbers are hard-coded in chart code
  except annotations that were typed into prose "so-what" notes (see §11 consistency rule).
- Single page, sticky top nav with anchor links and active-section highlighting (IntersectionObserver, rootMargin -40% 0 -55% 0).

## 3. DATA MODEL (ATLAS_DATA, accessed as D)  — shapes only
Terms (19): keys pref, nonpart, pool, antidil, conv, sec, coinv (Economic); board, vest, leaver, drag, consent (Control);
fwarr, cwarr, arrfee, monfee, excl, sust, dei (Other). D.terms = [{k,l,c}].
- D.stages = ['Seed','Series A','Series B','Series C+']; D.stageDef = ['<£2m','£2–10m','£10–30m','>£30m'].
- D.byStage.y2023|y2024|y2025[termKey] = [seed,A,B,C+] (% of term sheets containing the term). NB: 2023 Series B and C+ are IDENTICAL
  in the source (stages pooled in the 2024 edition) -> flag D.bcPooled2023=true and surface the caveat wherever 2023 B/C+ is used.
- D.byInvestor.y2023|y2024|y2025[termKey] = [VC(LP fund), VCT, EIS, CVC, Family office, Angel]; D.investorMeta=[{n,avg}] (2025 counts and avg cheque £m).
- D.bySector.y2024|y2025[termKey] = [AI(pure), DeepTech(ex-AI), Life Sci & BioTech] (no 2023).
- D.termSeries[key] = 5 values 2021..2025 (null = not surveyed): 19-term set plus tag, tranche, cosale, restrict, prefdiv, growth, dno, keyman, persguar.
  D.termSeriesLabels, D.termCat (category per series). D.liqType {nonpart,part,partcap}[5]. D.esg, D.dei by stage 2022..2025.
- Valuation: D.valuation[stage][5] median post-money £m 2021..25 (Pitchbook); D.avgInv[stage][5] average cheque £m; D.partPref[stage]=[2024,2025]
  % deals with participating pref; D.prefDiv likewise; D.stageMix[stage][5] % of term sheets by stage; D.sample (counts); D.kpi.
- Capital flows: D.leadVol[all|stage] = {n:[2023,24,25], UK[],Europe[],US[],Other[]} (% of lead investors by HQ); D.leadVal (origin £bn,
  origin share by stage for inbound £5.9bn of £8.8bn); D.macro {ukVC years/bn, conc (value by stage 2023-25), countries, exits, dryPowder}.
- Sectors: D.sectors [{n, s:[2022..2025 % share]}]; D.sectorYears; D.top10Share; D.deepTech {vol,val}[5]; D.sectorVal [{n,v,i,dt}] avg post-money
  and cheque £m (2026 ed.; 15 sectors); D.sectorVal24 (2025 ed.: avg PRE-money + cheque; methodology differs!); D.sectorStage {y2023,y2024}
  {n:[stage counts], rows:{sector:[counts by stage]}}; D.sectorShareEd; D.aiVal {years 2021..2024; per stage {ai[],ex[]}}.
- Geography: D.geoStage, D.geoSector (term sheets, London % by count, £m, London % by value), D.regions (9 regions: ts, avg cheque, pref %,
  non-part %, liq multiple, pool %, vesting %, investor mix [6]).
- Investor types over time: D.invVol, D.invVal, D.cvcSector, D.cvcStage, D.bigA (Series A >£50m pre-money table of 15 rounds), D.spinouts.
- Pulse survey: D.pulse {outlook, deals, focus, sectors, founderVal, structure} each row [label, 2025 %, 2026 %] (n=52 in 2025, n=41 in 2026).
- Misc: D.cplusCycle, D.seedPart, D.editions, D.exclusivityDays {y2024:34,y2025:48}, D.advice (term -> negotiation advice string).

## 6. 3D LANDSCAPE (Three.js) — details
- Grid: x = 19 terms (spacing 1.15), z = lanes (spacing 2.15). One BoxGeometry(0.78, 1, 1.2) mesh per cell scaled on Y; target height = value/100*9 (HEIGHT=9). Bars lerp
  toward target (0.12/frame). Floor plane + GridHelper + dashed rails at 25/50/75/100%.
- Controls: lane dimension [Stage | Investor type | Sector cohort]; mode [Prevalence (colour by category Economic/Control/Other, lightened as value falls) |
  Colour = delta vs prior year (diverging teal/rust saturating at +/-20pp) | Change landscape (height = delta*0.55*0.45, negative bars below floor)];
  edition year [2025|2024|2023] (sector dimension has no 2023 -> falls back to 2024; delta vs previous year, 2023 has none); prior-year ghost wireframes toggle;
  auto-orbit toggle; Reset view.
- Camera: spherical (theta -0.3, phi 1.0, target y 2.4). Hand-written pointer orbit (drag), wheel zoom (clamp 12..60), click selects, hover raycast + tooltip + readout card
  (value, prior year, change, lane average, rank, interpretive sentence). Auto-fit radius: max(22, (w/2+7)/(tan(21deg)*aspect)*0.95, (d/2+8)*1.5).
- Labels are DOM divs projected each frame (term labels rotated -55deg, right-aligned at the bar base; lane labels at right; 25..100% rail labels). They need `position:absolute;left:0;top:0`.
- Render loop pauses when off-screen (IntersectionObserver). Handle WebGL failure with a message. Mobile: readout card becomes static, stage height 520px.

## 9. DESIGN SYSTEM
- Theme: clean editorial LIGHT. Tokens (CSS vars): paper #faf8f4, paper2 #f3efe7, card #fff, ink #1c1b1a, ink2 #46433e, muted #7a756c, rule #e3ddd1, rule2 #cfc7b8,
  teal #0f6e6e (up/good), rust #c1502e (down/bad), plum #6b3f7a (investor accents), blue #2f55a4, ochre #c8932f.
- Stage colours: Seed #d9a024, A #2a8a86, B #3a5aa8, C+ #7a3b6e. Origin colours: UK #3a7d4f, Europe #3a5aa8, US #b3202a, Other #9a9186.
  Term category colours: Economic #2f55a4, Control #6b3f7a, Other #c8932f. Delta colours: teal = more common, rust = less common.
- Typography: Source Serif 4 for H1-H3, stat numbers; Inter for UI/body (15px/1.55). Max content width 1240px, card radius 12px, 1px rule borders, no shadows.
- Grid: .grid2/.grid3 collapse to 1 column <=900px; 16px gutters on mobile; no horizontal page scroll.
- Charts: inline SVG built with d3 via helper `mkSvg(id,height,margins)` returning {svg,g,w,h}; width = container clientWidth, viewBox scaling. Redraw all on resize (180ms debounce).
  Shared helpers: tooltip (#tip, follows cursor), yAxisGrid, legend, dodge/label-spreading, fmt.
- IMPORTANT CSS GOTCHA: do not set `fill` for SVG text via a plain CSS class rule if JS sets a `fill` attribute — the CSS wins and kills colours. Use `.lbl:not([fill]){fill:...}`.
- Pills: founder (teal tint), investor (plum tint), multi-year (ochre), neutral. "Do this" boxes are black with a small caps teal label.
- Interaction principles: hover tooltips on every mark; toggles are segmented controls (.seg); selects for cohort choices; keep numbers formatted (pp for percentage points, £m/£bn).

## 11. CONSIDERATIONS / RULES FOR CORRECTNESS
- Source discrepancy: the 2026 guide's executive-summary tile prints Series B+C+ share as 26% for 2025; its own stage chart gives 19%+12% = 31% -> use 31% and footnote.
- Derived metrics must be labelled as ours: IPI, equity sold (avgInv/valuation), sector price index, value/volume ratio, net expectation scores, implied origin x stage £ split.
- SpaceTech implied stake (36.7/44 = 83%) is an outlier -> flag. Sector valuations changed definition between editions (pre-money vs implied post-money): show direction only.
- Prose so-what/insight text embeds numbers: any data change MUST be re-checked against prose (consistency rule). Prefer computing numbers in code where feasible.
- Do not invent data not in the sources; label approximations. Not financial/legal advice (footer).
- Performance: pause WebGL when off-screen; avoid layout thrash; redraw only on resize/interaction.
- Accessibility: sufficient contrast, tooltips supplement visible labels, keyboard-usable native controls.
